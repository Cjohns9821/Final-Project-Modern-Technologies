The IT Ticket Management System is a web-based application designed to help organizations manage and track technical support requests. 
Many organizations rely on emails, spreadsheets, or verbal communication to report technical issues, which can lead to lost requests, duplicated work, and limited visibility into issue resolution. 
This application provides a centralized platform for creating, viewing, and managing support tickets.

The primary users of the system include employees, students, IT support technicians, and administrators who need an organized way to report and resolve technical problems. 
The system allows users to submit support requests with descriptions, assign priority levels, and designate responsible technicians. 
Support staff can monitor tickets throughout the support process and update their status as work progresses.

The MVP includes core ticket management functionality such as ticket creation, ticket viewing, technician assignment, priority management, and ticket status tracking. 
Tickets can be updated through multiple stages including Open, In Progress, and Closed, providing visibility into the support lifecycle.

The application is built using Python Flask for the backend and SQLite for data storage. 
Docker is used for containerization, GitHub for version control and collaboration, Jira for project management, Confluence for project documentation, and Google Cloud Platform for deployment. 
AI-powered development tools, including GitHub Copilot and ChatGPT, were used to assist with code generation, debugging, planning, and documentation throughout the development process.

This MVP demonstrates the use of modern software development practices, including Agile project management, cloud deployment, containerization, version control workflows, and AI-assisted software development.
