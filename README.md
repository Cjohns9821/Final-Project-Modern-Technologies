The IT Ticket Management System is a web-based application designed to help organizations efficiently manage technical support requests. 
Many businesses, schools, and organizations rely on email, spreadsheets, or verbal communication to report technical issues, which can result in lost requests, duplicated work, and poor tracking of issue resolution. 
This application provides a centralized platform where users can submit, view, and track support tickets while allowing support staff to manage requests more effectively.
The target users include employees, students, IT support technicians, and administrators who need an organized method for reporting and resolving technical problems. 
Users need a simple way to submit and monitor requests, while administrators need tools to assign, prioritize, and track support activity.
Core features include ticket submission, ticket status tracking (Open, In Progress, Resolved, and Closed), ticket search and filtering, and an administrative dashboard for managing support requests and viewing metrics. 
The application will be built using HTML, CSS, Bootstrap, and JavaScript for the frontend, Python Flask for the backend, and PostgreSQL for data storage. 
Docker will be used for containerization, GitHub Actions for CI/CD automation, and Google Cloud Platform for deployment.
AI integration will assist with ticket categorization, priority recommendations, and automated response suggestions.
